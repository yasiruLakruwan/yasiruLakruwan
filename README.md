# 🚀 Featured Projects

### 📚 **KnowFlow AI — Agentic RAG System**

An agentic Retrieval-Augmented Generation system for querying lecture materials.

* Planner & Critic multi-agent architecture
* Hybrid retrieval using **BM25 + vector search**
* Cross-encoder reranking
* Section-aware document chunking
* RAG evaluation using **RAGAS**
* React-based frontend
* MongoDB-based observability

**Tech:** Python • LangChain • LLMs • ChromaDB • MongoDB • React • RAGAS

### 🎵 **Music Genre Classification**

An end-to-end deep learning system for music genre classification.

* Converts audio into **Mel-Spectrograms**
* CNN-based genre classification
* Achieved **82% accuracy across 10 genres**
* Automated data processing using **Astro-Airflow**
* CI pipeline using **Jenkins & Docker**
* Dataset and artifacts stored using **AWS S3**

**Tech:** Python • TensorFlow • CNN • Librosa • Airflow • Jenkins • Docker • AWS
